# Formgong themes: the free website templates for WordPress and Shopify

Formgong's free website templates (https://formgong.com/en/website-templates/) as WordPress block themes and
Shopify themes. Each one looks like its template's demo and keeps its form working: on WordPress the form is the
free [Formgong plugin](https://wordpress.org/plugins/formgong/)'s block, so messages reach your Formgong inbox,
email and Telegram.

| Template | WordPress | Shopify |
|---|---|---|
| [Craftline](https://formgong.com/en/website-templates/craftline/) (trades) | [craftline-wordpress.zip](https://github.com/formgong-hq/formgong-themes/releases/tag/craftline-wordpress-1.0.0) | in progress |

More templates are on the way.

## Install a WordPress theme

1. Download `<template>-wordpress.zip` from the template's release. Don't unzip it.
2. In WordPress, open Appearance → Themes → Add New Theme → Upload Theme, choose the file, then Activate.
3. Install the Formgong plugin (Plugins → Add New → search "Formgong") and paste your access key under
   Settings → Formgong. Create a free key at https://formgong.com/new.
4. Optional: download `<template>-wordpress-pages.xml` from the same release and import it under
   Tools → Import → WordPress to get the template's demo pages and menu.

Each theme was checked on the latest WordPress with Theme Check, WP_DEBUG on, the Site Editor and a real form
submission. The checks are listed in each release.
