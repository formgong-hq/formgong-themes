A dark block theme for an analytics firm, consultancy or studio, with a moving network hero and an enquiry form that sends to Formgong.

== Description ==

Orrery is the WordPress version of the free Orrery website template (https://formgong.com/en/website-templates/orrery/).

* Home page: a hero with a moving network and four numbers, a media band, services, "when we say no", the process and a call to action.
* Page layouts for Services, About, Contact and Thanks, under Add page → Patterns → Orrery.
* Demo pages in one go: download orrery-wordpress-pages.xml from the Orrery release on GitHub, then Tools → Import → WordPress. It adds Services, About, Contact, Thanks and the menu.
* The enquiry form is the Formgong plugin's block (template "orrery"). Install the free Formgong plugin, paste your access key under Settings → Formgong, and the form sends every enquiry to your Formgong inbox and to Telegram.
* Motion (the network, the footer wave, enter animations) stops when the visitor asks for reduced motion.

= Make it yours =

The header, footer and home sections carry sample details of a fictional analytics firm, Quillmoor Analytics. Edit them in Appearance → Editor (Patterns and Templates), and set the menu in the Navigation block. The site title (Settings → General) is the first line of the logo; the small second line ("Analytics.") sits in the header part. The phone menu adds Home, the call button and the contact line: they are items of the same menu, marked to show only there, so edit them in the Navigation block too. To send visitors to your Thanks page after the form, set its address as the redirect under Settings → Formgong.

== Frequently Asked Questions ==

= The enquiry form does not show =

Install and activate the Formgong plugin, then paste your access key under Settings → Formgong.

= Can I use the theme without Formgong? =

Yes. Remove the form block, or replace it with another form plugin's block.
